# NFTStudioElite

NFTStudioElite enables secure, blockchain-based, decentralized marketplaces with real-time transaction execution on a robust, wallet-integrated platform, utilizing explorer-based tracking.

NFTStudioElite is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTStudioElite.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

NFTStudioElite is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
